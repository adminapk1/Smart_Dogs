# STC11L08XE + LD3320 语音识别 → UART → STC89C52 驱动方案

## 概述

本项目当前架构：STC11L08XE (5V) + LD3320 语音识别模块，STC11L08XE 通过 UART 发送 `[0xAA][命令码]` 给 STC89C52；STC89C52 再驱动 OLED、舵机和状态指示灯。

**问题**：上电 LD3320 无法解析预设语言指令，串口通信失败，舵机驱动抖动严重。

**解决方案**：校正 UART 波特率与晶振关系，统一两片 MCU 的波特率为 1200，添加状态灯和串口命令日志，修正舵机 PWM 时基与命令处理逻辑，最终实现 STC11L08XE 与 STC89C52 通讯正常，舵机动作稳定。

## 通信协议 通过 UART 串口

### 格式

```
STC11L08XE → STC89C52 (单向):

发送顺序: [0xAA] [命令码]

- 0xAA     : 协议头，标识一条命令的开始
- 命令码    : 1字节，对应语音识别结果码 (CODE_xxx)
```

### 协议特点

1. **帧同步简单**：STC89C52 接收到 0xAA 后进入等待命令状态，下一个字节作为命令码立即执行
2. **无应答机制**：单向通信，STC89C52 不回复，减少协议开销
3. **可靠保障**：如果数据错位（丢失 0xAA），命令码会被忽略，不会产生误动作

| 命令码          | 值     | 语音命令       | STC89C52 动作        |
|----------------|:------:|:-------------:|:--------------------:|
| CODE_CMD       | 0x00   | "小杰" (唤醒)  | 可选：点亮工作指示灯    |
| CODE_1         | 0x01   | "开灯"        | P1.1 = 1 (灯亮)      |
| CODE_2         | 0x02   | "关灯"        | P1.1 = 0 (灯灭)      |

| CODE_8         | 0x18   | "关闭空调"     | P1.0 = 0 (表情灭)     |
| CODE_10        | 0x1A   | "举左手"      | P1.3 = 1 (左舵机开)   |
| CODE_13        | 0x1D   | "停止左手"     | P1.3 = 0 (左舵机关)   |

## STC89C52 代码说明

文件位置：`SmartDogs/UartSTC89C52/uartSTC89.c`

### 编译环境
- Keil C51 uVision
- Device: STC89C52RC / AT89S52
- 晶振: 11.0592MHz (推荐，1200 波特率精确)
- 如需使用其他晶振频率，需重新计算 TH1 值

### 波特率计算方法
```
波特率 = 晶振频率 / 12 / 32 / (256 - TH1)

@11.0592MHz:
9600 = 11059200 / 384 / (256 - TH1)
256 - TH1 = 3
TH1 = 253 = 0xFD
```

### 代码结构
- **main()**: 初始化IO和UART，主循环空闲
- **UART_ISR() (interrupt 4)**: 串口接收中断，使用状态机解析协议
- **ProcessCommand()**: 解析命令码并驱动IO口
- **DelayMs()**: 毫秒延时函数

### 中断状态机接收流程
```
IDLE 状态: 等待 0xAA
    收到 0xAA → 切换到 CMD 状态
    收到其他   → 忽略，保持 IDLE
    
CMD 状态:  等待命令码
    收到任意字节 → 执行 ProcessCommand()
                → 切回 IDLE 状态
```

## STC11L08XE 修改说明

在原有 `main.c` 基础上：

1. **新增函数 `UARTSendCmdTo89C52(cmd)`**
   - 发送 0xAA + 命令码到 STC89C52
   
2. **修改 `User_handle()` 函数**
   - 移除了对 P1.4-P1.7 的直接 GPIO 控制（SRD1-SRD4 不再被操作）
   - 保留了对 PC 串口的 PrintCom 调试输出
   - 每个识别结果都调用 `UARTSendCmdTo89C52()` 发送命令码

3. **IO定义移除**
   - 原代码中的 `sbit SRD1 = P1^7;` 等定义已移除
   - STC11L08XE 不再直接驱动外围设备

## 使用步骤

### STC11L08XE 侧（语音板）
1. 使用 Keil C51 打开原工程
2. 将 `main.c` 替换为本项目的版本
3. 连接 STC11L08XE 的 P3.1 (TXD) 到 STC89C52 的 P3.0 (RXD)
4. 连接 GND 共地
5. 编译下载

### STC89C52 侧（驱动板）
1. 使用 Keil C51 新建工程，Device 选择 STC89C52RC
2. 添加 `STC89C52/main.c` 到工程
3. 晶振频率设置为 11.0592MHz
4. 编译下载
5. 按硬件连接图连接外围设备

## 注意事项


1. **晶振选择**：
   - STC11L08XE: 22.1184MHz（原设计，无需修改）
   - STC89C52: 推荐 11.0592MHz（如果使用其他频率需重新计算 UART 波特率）

2. **波特率一致性**：两块单片机 UART 必须设置为相同的波特率 (1200)

3. **驱动电流**：
   - STC89C52 每个 IO 口最大灌电流约 20mA，源电流约 200μA
   - 驱动 LED 建议使用灌电流方式（LED 正极接 VCC，负极接 IO 口）
   - 驱动舵机建议通过三极管或光耦隔离

4. **上电顺序**：先给 STC89C52 上电，再给 STC11L08XE 上电，可避免 STC11L08XE 未初始化时 STC89C52 串口误接收
